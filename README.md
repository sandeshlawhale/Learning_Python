# Automate the Boring Stuff with Python

![Book Cover](book-image.png)

This repository contains my complete hands-on learning journey through the book **Automate the Boring Stuff with Python** by Al Sweigart.

The main purpose of this repository is not just to store code, but to document concepts, practice exercises, mini projects, notes, experiments, and automation scripts that I built while learning Python.

---

# Repository Structure

Every chapter is organized in a structured and easy-to-follow format.

Example:

```text
1. python basics/
│
├── 1.1 variables.py
├── 1.2 data types.py
├── 1.3 operators.py
├── 1.4 practice questions.txt
└── 1.5 practice projects.py
```

Each chapter folder contains:

- Topic-wise Python files
- Detailed comments explaining every important line
- Practice questions with short and clear answers
- Practice projects from the book
- Additional experiments and custom improvements

The goal was to make the repository useful not only for revision, but also for anyone learning Python from scratch.

# What I Learned

This book taught me far more than I originally expected.

Before starting this book, automation felt complicated and advanced. But chapter by chapter, it showed how Python can interact with files, folders, PDFs, spreadsheets, emails, browsers, images, APIs, and even the keyboard and mouse.

The biggest strength of this book is that it focuses on building practical things instead of only explaining theory.

By completing this book, I learned:

- Python fundamentals
- File handling
- Automation scripting
- Web scraping
- Spreadsheet automation
- PDF and Word processing
- Email automation
- Working with APIs and JSON
- Scheduling tasks
- Image processing
- GUI automation
- Real-world scripting workflows

# Important Note

Some parts of this book are old, and a few libraries or methods are now deprecated or updated in modern Python versions.

However, the concepts, problem-solving approach, and automation mindset taught in this book are still extremely valuable.

Even today, this book teaches more practical automation and scripting knowledge than many tutorial playlists and short-form videos online.

While working through the chapters, I updated several examples to work with modern Python versions and newer library changes wherever necessary.
